# gps

This project is a mobile-friendly web GPS application designed to track routes, trails, and real-time movement. The interface displays live location data such as latitude, longitude, speed, altitude, GPS accuracy, and heading, making it useful for outdoor navigation and route monitoring.

The app allows users to start recording a trip, measure distance traveled, total time, moving time, average speed, maximum speed, and altitude gain/loss. It also includes a route chart for altitude profiles and supports exporting the recorded track in GPX format. In addition, users can mark waypoints and navigate back to them, making the tool useful for hiking, off-road travel, and route planning.

Beyond GPS tracking, the project includes orientation and navigation features such as a compass, direction indicators, tilt/inclination monitoring, and visual/audio alerts when the configured threshold is exceeded. It also includes weather information using Open-Meteo data and a night mode for better visibility in low-light conditions.

Over time, the project evolved from a simple location page into a more complete field GPS tool. Its development included improvements to the map interface, responsive mobile layout, waypoint marking, route saving, night mode styling, SVG-based display enhancements, and optimization for small screens. It also received refinements for sensor-based orientation and motion tracking.

In summary, this project functions as a trail GPS dashboard, combining map display, route recording, navigation, inclination monitoring, and environmental data in a simple and practical mobile web app.
